CloudSync Platform - API Documentation

Base URL: https://api.cloudsync.techcorp.com/v1

Authentication:
All API requests require authentication using either OAuth 2.0 or API keys.

OAuth 2.0 Flow:
1. Obtain access token: POST /oauth/token
2. Include in header: Authorization: Bearer {access_token}
3. Token expiry: 1 hour (refresh token valid for 30 days)

API Key Authentication:
Include in header: X-API-Key: {your_api_key}

Endpoints:

1. Resources Management

GET /resources
List all cloud resources across providers
Query Parameters:
  - provider: Filter by cloud provider (aws|azure|gcp)
  - status: Filter by status (running|stopped|terminated)
  - tags: Filter by resource tags
  - limit: Number of results (default: 50, max: 200)
  - offset: Pagination offset

Response:
{
  "resources": [
    {
      "id": "res_abc123",
      "type": "virtual_machine",
      "provider": "aws",
      "region": "us-east-1",
      "status": "running",
      "created_at": "2025-10-15T10:30:00Z",
      "metadata": {
        "instance_type": "t3.medium",
        "cpu": 2,
        "memory_gb": 4
      }
    }
  ],
  "total": 150,
  "limit": 50,
  "offset": 0
}

POST /resources
Create a new cloud resource
Request Body:
{
  "type": "virtual_machine",
  "provider": "aws",
  "region": "us-west-2",
  "configuration": {
    "instance_type": "t3.large",
    "ami": "ami-12345678",
    "security_groups": ["sg-default"],
    "tags": {"Environment": "production"}
  }
}

Response:
{
  "resource_id": "res_xyz789",
  "status": "provisioning",
  "estimated_completion": "2025-10-31T14:45:00Z"
}

GET /resources/{resource_id}
Get details of a specific resource

DELETE /resources/{resource_id}
Terminate a resource
Query Parameters:
  - force: Force termination (true|false)
  - retain_storage: Keep storage volumes (true|false)

2. Cost Analytics

GET /costs/summary
Get cost summary across all providers
Query Parameters:
  - start_date: ISO 8601 format (YYYY-MM-DD)
  - end_date: ISO 8601 format (YYYY-MM-DD)
  - group_by: Grouping dimension (provider|service|region|tag)

Response:
{
  "total_cost": 125430.50,
  "currency": "USD",
  "period": {
    "start": "2025-10-01",
    "end": "2025-10-31"
  },
  "breakdown": [
    {
      "category": "compute",
      "cost": 85230.20
    },
    {
      "category": "storage",
      "cost": 28140.80
    },
    {
      "category": "network",
      "cost": 12059.50
    }
  ]
}

GET /costs/forecast
Get cost forecast for next period
Query Parameters:
  - months: Forecast horizon (1-12)
  - confidence_level: Confidence interval (0.90|0.95|0.99)

3. Monitoring and Alerts

GET /metrics
Get performance metrics for resources
Query Parameters:
  - resource_id: Specific resource or "all"
  - metric_type: cpu|memory|disk|network
  - start_time: ISO 8601 timestamp
  - end_time: ISO 8601 timestamp
  - aggregation: avg|sum|min|max

POST /alerts
Create a new alert rule
Request Body:
{
  "name": "High CPU Alert",
  "resource_id": "res_abc123",
  "metric": "cpu_utilization",
  "condition": "greater_than",
  "threshold": 80,
  "duration_minutes": 5,
  "notification_channels": ["email", "slack"]
}

4. Security and Compliance

GET /compliance/status
Get compliance status for all resources
Query Parameters:
  - framework: gdpr|hipaa|soc2|iso27001

Response:
{
  "framework": "gdpr",
  "compliance_score": 0.95,
  "compliant_resources": 142,
  "non_compliant_resources": 8,
  "issues": [
    {
      "resource_id": "res_abc123",
      "issue": "Encryption not enabled",
      "severity": "high",
      "remediation": "Enable AES-256 encryption"
    }
  ]
}

Rate Limits:
- Standard: 1000 requests/minute
- Enterprise: 5000 requests/minute
- Burst: 2x standard rate for 1 minute

Error Codes:
- 200: Success
- 201: Resource created
- 400: Bad request (invalid parameters)
- 401: Unauthorized (invalid credentials)
- 403: Forbidden (insufficient permissions)
- 404: Resource not found
- 429: Rate limit exceeded
- 500: Internal server error
- 503: Service unavailable

Error Response Format:
{
  "error": {
    "code": "invalid_parameter",
    "message": "The 'provider' parameter must be one of: aws, azure, gcp",
    "request_id": "req_abc123xyz"
  }
}

Webhooks:
Configure webhooks to receive real-time events
POST /webhooks
Request Body:
{
  "url": "https://your-app.com/webhook",
  "events": ["resource.created", "resource.deleted", "alert.triggered"],
  "secret": "your_webhook_secret"
}

SDK Examples:

Python:
```python
from cloudsync import CloudSyncClient

client = CloudSyncClient(api_key="your_api_key")
resources = client.resources.list(provider="aws", status="running")
```

JavaScript:
```javascript
const CloudSync = require('@techcorp/cloudsync-sdk');
const client = new CloudSync({ apiKey: 'your_api_key' });
const resources = await client.resources.list({ provider: 'aws' });
```
